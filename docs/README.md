## Public-repository safety

This GitHub repository is public. The following private operating assets are intentionally **not** committed:

- Live environment files, API keys, admin credentials, password hashes and session secrets
- Raw international-client CRM workbook
- Named first-wave target-account list
- Prospect email addresses, buyer profiles and account-specific outreach hypotheses
- Temporary workbook builders, previews and deployment archives

Those assets should live in a separate private repository or secured CRM. Do not use forced Git staging to bypass `.gitignore`.

## Freshness rule

Provider capabilities, pricing, event dates, buyer roles and company facts change. Re-verify time-sensitive information on the actual send or production date. A planning document is evidence of preparation—not proof of demand, budget or ROI.
